core:fmt

Formatted I/O — format verbs, flags, and the key procedures of the fmt package.

Package Overview

core:fmt provides formatted input/output procedures with format verbs derived from C's printf but simplified.

  • Collection: core
  • Package: fmt
  • Import path: core:fmt
  • Procedures: 82
  • Types: 4 (Info, Info_State, Register_User_Formatter_Error, User_Formatter)

Format Verbs

General

VerbMeaning
%vValue in default format
%#vExpanded format (newlines, indentation)
%wOdin-syntax representation of the value
%TOdin-syntax representation of the type
%%Literal percent sign
{{Literal open brace
}}Literal close brace
{:v}Python-like equivalent of %v

Boolean

VerbMeaning
%tThe word "true" or "false"

Integer

VerbMeaning
%bBase 2 (binary)
%cCharacter represented by Unicode code point
%rSynonym for %c
%oBase 8 (octal)
%d / %iBase 10 (decimal)
%zBase 12 (dozenal)
%xBase 16 hex (lowercase a-f)
%XBase 16 hex (uppercase A-F)
%UUnicode format: U+1234

Byte Size

VerbMeaning
%mBytes in best unit (e.g. 123.45mib)
%MBytes in best unit (e.g. 123.45MiB)

Floating-Point

VerbMeaning
%e / %EScientific notation
%f / %FDecimal point, no exponent
%g / %GSynonyms for %f with default max precision
%h / %HHexadecimal with 0h / 0H prefix

Strings & Bytes

VerbMeaning
%sUninterpreted bytes of string or slice
%qDouble-quoted string, Odin-escaped
%x / %XBase 16 hex, two chars per byte

Pointers & Memory

VerbMeaning
%pAddress in base 16 with 0x prefix

Format Flags

FlagEffect
+Always print sign for numeric values
-Left-justify (pad right)
#Alternate format: 0b, 0o, 0z, 0x prefixes
 Space for elided sign
0Pad with leading zeros

Width is specified by a decimal number after %. Precision follows a period (.2f).

Example

import "core:fmt"

main :: proc() {
   name := "Odin"
   version := "dev-2026-10"
   count := 42
   price := 19.99

   fmt.printfln("Welcome to %s, version %s", name, version)
   fmt.println("Count: %d, Price: %.2f", count, price)
   fmt.println("Type of version: %T", version)
   fmt.println("Hex: %x, Binary: %b", 255, 255)
   fmt.println("Pointer: %p", &count)
}

Format Errors

Invalid arguments produce descriptive error strings in output:

  • %!(BAD ENUM VALUE)
  • %!(EXTRA, ...)
  • %!(MISSING ARGUMENT)
  • %!(BAD WIDTH)
  • %!(BAD PRECISION)
  • %!(NO VERB)
  • %!(BAD ARGUMENT NUMBER)
  • %!(MISSING CLOSE BRACE)
