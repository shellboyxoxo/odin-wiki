Core Syntax

Fundamental syntax of the Odin programming language — packages, imports, declarations, blocks, comments, and control flow.

Package Declaration

Every Odin source file begins with a package declaration. The package name determines how other files import it.

package main

If no package is declared, the compiler infers it from the directory name or file name.

Import Statement

Odin uses library collections to organize imports. The prefix before the colon tells the compiler which collection to search.

import "core:fmt"
import "core:os"
Library Collections
core: — Core library (fmt, os, mem, strings, time, etc.)
base: — Base library (runtime, intrinsics, containers)
vendor: — Third-party library bindings (raylib, sdl3, curl, etc.)

You can also give an import a different name:

import "core:fmt"
import foo "core:fmt" // reference as foo instead of fmt

Comments

Odin supports line comments with //:

// This is a line comment
x := 42 // inline comment

Variables and Constants

Variable Declaration

Odin uses := for declaration with inference, and = for assignment:

x := 42                       // declare and infer type (int)
y := "hello"                // declare and infer type (string)
z: int = 100                  // explicit type declaration
z = 200                       // assignment (already declared)

Constants

Use constant or const for compile-time values:

constant Max_Users := 100
const Pi := 3.14159

Blocks and Scope

Odin uses braces { } for blocks. Variables declared inside a block are scoped to that block:

main :: proc() {
    x := 10                       // scoped to main
    {
        y := 20                   // scoped to inner block
        fmt.println(x + y)        // 30
    }
    // fmt.println(y)              // error: y not in scope
}

Control Flow — if / else

Odin's if does not require parentheses around the condition:

main :: proc() {
    age := 18
    if age >= 18 {
        fmt.println("adult")
    } else {
        fmt.println("minor")
    }

    // if with initializer (like Go)
    if x := compute_value(); x > 0 {
        fmt.println("positive: %v", x)
    }
}

Control Flow — switch

Odin's switch is a powerful construct. Cases do not fall through by default:

main :: proc() {
    day := "Monday"
    switch day {
    case "Monday":
        fmt.println("start of week")
    case "Friday":
        fmt.println("end of week")
    case "Saturday", "Sunday":
        fmt.println("weekend")
    else:
        fmt.println("weekday")
    }

    // switch without expression (like if/else chain)
    switch {
    case x < 0:
        fmt.println("negative")
    case x == 0:
        fmt.println("zero")
    else:
        fmt.println("positive")
    }
}

Control Flow — for loop

Odin uses for for all looping. There is no while or do-while:

main :: proc() {
    // C-style for
    for i := 0; i < 5; i += 1 {
        fmt.println("i = %v", i)
    }

    // condition-only (like while)
    for x < 10 {
        x += 1
    }

    // infinite loop
    for {
        break  // or this runs forever
    }

    // range over array
    arr := [3]int{10, 20, 30}
    for i in arr {
        fmt.println("value: %v", i)
    }

    // range with index
    for i, v in arr {
        fmt.println("index: %v, value: %v", i, v)
    }
}

Procedure Declaration

Procedures are declared with proc. The procedure name uses :: as a separator:

add :: proc(a: int, b: int) -> int {
    return a + b
}

Multiple return values are supported:

divmod :: proc(a: int, b: int) -> (quotient: int, remainder: int) {
    return a / b, a % b
}

main :: proc() {
    q, r := divmod(10, 3)
    fmt.println("q: %v, r: %v", q, r)  // q: 3, r: 1
}

Entry Point

Every executable Odin program needs a main procedure in the main package:

package main

import "core:fmt"

main :: proc() {
    fmt.println("Hello, Odin!")
}

Compile and run:

odin run main.odin
Hello, Odin!
