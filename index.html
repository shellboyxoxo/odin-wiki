Home

Welcome to the Odin Wiki — a reference for the Odin programming language, its standard library, and vendor bindings.

Overview

Odin is a general-purpose programming language with distinct typing, built for high performance, modern systems, and built-in data-oriented data types. It is often described as the C alternative for the joy of programming.

The language emphasizes clarity, simplicity, and explicitness. It is designed as a C alternative that aims to provide the joy of programming while maintaining performance and control.

Quick Start

Install Odin on Arch Linux:

sudo pacman -S odin

Verify the installation:

odin version
odin version dev-2026-10:84bc3fc21

Create your first file, hello.odin:

package main

import "core:fmt"

main :: proc() {
    fmt.println("Hello, Odin!")
}

Compile and run:

odin run hello.odin
Hello, Odin!
