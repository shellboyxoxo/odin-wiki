Overview

Odin is a general-purpose programming language with distinct typing, built for high performance, modern systems, and built-in data-oriented data types. It is often described as the C alternative for the joy of programming.

Latest Release: dev-2026-10
Released October 6, 2026 (commit 84bc3fc). Key highlights:
  • New language feature: Allow bit_set to be backed by arrays of integers.
  • Speedups: LLVM backend performance improvements, parapoly rewrite, multithreaded semantic checker, and map performance improvements.
  • Package collections: base, core, and vendor — over 200 packages and 100,000+ declarations across all collections.

The vendor collection contains 54 packages (26,903 declarations) with bindings to popular third-party libraries for graphics, windowing, audio, physics, and more — all shipped with the compiler under the zlib license.

Vendor Libraries

The vendor collection provides Odin bindings to widely-used C and C++ libraries. These are shipped with the compiler and ready to import via vendor:<name>.

CategoryVendor PackagesUse Case

Example: Using vendor:raylib
package main

import "vendor:raylib"
import "core:fmt"

main :: proc() {
    rl.InitWindow(800, 450, "Odin + raylib")
    defer rl.CloseWindow()

    for not rl.WindowShouldClose() {
        rl.BeginDrawing()
        rl.ClearBackground(rl.RAYWHITE)
        rl.DrawText("Hello from Odin!", 190, 200, 20, rl.VIOLET)
        rl.EndDrawing()
    }
}

core:fmt — Formatted I/O

core:fmt provides formatted input/output with procedures similar to C's printf and Python's format. Format verbs are derived from C's but simpler.

Common format verbs

VerbMeaningExample
%vDefault formatfmt.println("value: %v", x)
%#vExpanded format (newlines, indentation)fmt.printfln("%#v", my_struct)
%TOdin-syntax type representationfmt.println("%T", value)
%tBoolean "true"/"false"fmt.println("%t", flag)
%d / %iBase 10 integerfmt.println("%d", count)
%x / %XBase 16 hex (lower/upper)fmt.println("%x", flags)
%bBase 2 binaryfmt.println("%b", bits)
%fDecimal floating-pointfmt.println("%.2f", price)
%sRaw bytes of string/slicefmt.print("%s", name)
%qDouble-quoted, Odin-escaped stringfmt.println("%q", s)
%pPointer address (base 16, 0x prefix)fmt.println("%p", ptr)

Key procedures (82 total)

  • print, printf, printfln, println — stdout output
  • eprint, eprintf, eprintfln, eprintln — stderr output
  • fprint, fprintf, fprintfln, fprintln — file output
  • aprint, aprintf, aprintfln, alprintln — allocated string output
  • tprint, tprintf, tprintfln, tprintln — temporary allocator string output
  • panicf, assertf, ensuref — formatted panics and assertions
import "core:fmt"

main :: proc() {
    name := "Odin"
    version := "dev-2026-10"
    fmt.printfln("Welcome to %s, version %s", name, version)
    fmt.println("Type of version:", "%T", version)
}

Quick Reference

Important
The Odin compiler is still in development. Breaking changes may occur between releases.

Basic program structure

package main

import "core:fmt"

main :: proc() {
    fmt.println("Hello, Odin!")
}

Compile and run

odin run .           # compile and run current directory
odin build .         # build executable
odin file main.odin  # type-check a single file
