Getting Started

Install Odin, verify your toolchain, and run your first program.

Requirements

  • Odin dev-2026-10 or newer — check with odin version.
  • Any 64-bit platform the Odin compiler targets (Linux, Windows, macOS, WASM).
  • No C compiler required for basic programs — Odin ships with its own runtime.
Vendor bindings may need system libraries
Third-party bindings in the vendor: collection (for example vendor:sdl3) can depend on system libraries that must be installed separately. See Vendor Overview.

Installation

PlatformHow
Arch Linuxsudo pacman -S odin
Linux (others)Download the pre-built binary for your platform from the releases page, or use the official install script from the Odin repository.
WindowsDownload the release zip from the releases page and add the folder to your PATH.
macOSSame as other platforms: pre-built binary from the releases page.

Verify the Toolchain

odin version
odin version dev-2026-10:84bc3fc21

That prints the release name and commit. It is the version this wiki documents.

Run Your First Program

Create a file called hello.odin:

package main

import "core:fmt"

main :: proc() {
    fmt.println("Hello, Odin!")
}

Run it directly — the compiler handles the rest:

odin run hello.odin
Hello, Odin!

When you want a standalone executable, build it instead:

odin build hello.odin
./hello
run vs build
odin run compiles and executes in one step — best while iterating. odin build produces a binary you can ship.
